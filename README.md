# Projeto-Escola-EAD-Joel-Robles
Sistema de gerenciamento de uma Escola EAD desenvolvido em Java e BlueJ. O projeto aplica conceitos de POO, como encapsulamento, herança, polimorfismo e validações, além de arrays, cadastro de alunos e cursos, lançamento de notas, cálculo de médias e controle de mensalidades.
